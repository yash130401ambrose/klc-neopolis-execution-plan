## Presenting

| Key | Action |
| --- | --- |
| `→` / `space` | Next slide |
| `←` | Previous slide |
| `M` | Slide index |
| `F` | Fullscreen |

Slides also respond to swipe, and the current slide is kept in the URL hash.

## The versions

All three files are the same 15-slide deck:

- `index.html` — all 14 stages on a full-width ruler, grouped Foundation / Basement / Podium / Tower / Typical / Roof.
- `structure-option-2.html` — five phases listed beside the video, each expanding to its breakdown when active.
- `v3.html` — **Brigade Barcelona**, matching the 18-09-2026 deck: 40 months overall (35 structure + 5 finishing), 11-day typical floor cycle, revised stage durations (raft 30, B1 30, Eco Desk 30, terrace 20 days), 2 tower cranes and 3 SPBs.

## Images

Photographs in `assets/` are placeholders. Replace a file with your own, keeping the same filename:

| File | Used on |
| --- | --- |
| `cover.jpg` | Cover |
| `about-klc.jpg` | About KLC |
| `philosophy.jpg` | How we work |
| `machinery.jpg` | Plant & machinery |
| `controls.jpg` | Project controls |
| `closing.jpg` | Our commitment |
| `build-timelapse.mp4` | Structure (drives the phase captions) |


Empty slots show a dashed placeholder; you can also drag an image onto one to preview it without saving.

The logistics slide now carries a generic site plan drawn in the page — swap it for the issued drawing when it is available.

## Known content conflicts

`index.html` and `structure-option-2.html` still carry the original Neopolis figures. `v3.html` follows the Brigade Barcelona deck, except the milestones slide keeps the client's marked-up figures — foundation & raft **75 days** and podium **45 days** — where the deck says 30-day work fronts and 45 + 30 days.
